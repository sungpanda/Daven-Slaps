# Daven Slaps 🌊🪨

> **A retro pixel-art stone skipping arcade game featuring rhythmic bounce timing, dynamic wind physics, absurd hazards, and the infamous "Daven Slaps" rage bait level.**

---

## 🎮 About The Game

**Daven Slaps** puts your wrist timing and precision to the ultimate test. Select your stone, charge your throw, read the changing coastal winds, and tap in rhythm as your stone skims the water surface.

Earn **Bamboo** currency with distance to unlock heavier, faster waters—and test your sanity against **Davin**, the blissfully napping hedgehog who will snore your pebble straight into the abyss!

---

## 🦔 The Rage Bait Level: *Davin's Slumber*

> *"He's literally just sleeping and you still lost."*

In **Daven Slaps**, the river runs through a dreamy twilight sanctuary where **Daven** blocks the entire path on a water cushion. But don't let his adorable sleeping pose fool you:
- **Snore Suction:** Daven's massive snores pull passing pebbles towards him with unpredictable lateral turbulence.
- **Dream Shockwaves:** Every few seconds, Daven exhales a colossal snore wave. Time your skip to ride the crest—or watch your pebble get deflected straight into the depths!
- **Sleeping The Pabble Away:** Daven blocks the whole lane and swallows your pebble in his sleep without ever waking up.

---

## ✨ Features

- **Rhythmic Water-Skim Timing:** Hit the skip window at water contact. Perfect hits trigger golden arcs and high-speed skips.
- **5 Progressive Levels + Endless Mode:** Traverse calm creeks, toxic wreckage waters, and open ocean.
- **Dynamic Wind & Water Caustics:** Procedural top-down water shader with realistic caustics, wave swells, and drift currents.
- **Unique Stones:**
  - **Flat Slate:** High aerodynamic lift and smooth glide.
  - **Floaty Biscuit:** Bouncy, light, and hyper-sensitive to crosswinds.
  - **Actual Brick:** Zero aerodynamics. Pure comedy.
- **Audio Synthesizer:** Fully custom Web Audio API procedural sound engine with realistic splashes, comedic bonks, quacks, and Daven's snoring waves.
- **Full Touch & Keyboard Controls:** Play seamlessly on desktop or mobile.

## 🕹️ Controls

| Action | Keyboard | Touch / Mouse |
|---|---|---|
| **Steer Aim** | `A` (Left) / `D` (Right) | Tilt / Screen sides |
| **Charge Throw** | Hold `Space` | Press & Hold Canvas |
| **Release Throw** | Release `Space` | Release Canvas |
| **Skip (Bounce)** | Tap / Hold `Space` on impact | Tap Canvas on impact |
| **Quick Restart** | `R` | Reset Button |

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm, pnpm, or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/sungpanda/skip-or-sink.git
cd skip-or-sink

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
